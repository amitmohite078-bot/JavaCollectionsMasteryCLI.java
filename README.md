# ⚡ Java Collections & Streams Mastery Engine

An all-in-one interactive platform and CLI engine to master Java Collections (`ArrayList`, `LinkedList`, `HashSet`, `TreeSet`, `HashMap`) and `Java Streams` with deep JVM architecture, live sandboxes, 20 production scenarios per topic, 20 interview Q&As, and mastery quizzes.

---

## 🌟 Key Features

- **Interactive Full-Stack Web GUI**: Real-time REST API mutations, live memory visualization, and complexity streams (`http://localhost:8080`).
- **Interactive Terminal CLI**: Rich ASCII box rendering, formatted tables, and interactive sandboxes.
- **Deep Architecture**: Engine definitions, memory layout, time/space complexities, advantages, and trade-offs.
- **Operations Deep Dive**: Step-by-step internal JVM mechanics for Insertion, Deletion, Searching, and Sorting.
- **20 Real-World Industry Scenarios per Topic**: Practical engineering challenges (caching, telemetry, sliding windows, sharding).
- **20 Technical Interview Q&As per Topic**: Tiered into Service-Based vs Product-Based questions.
- **Interactive Mastery Quizzes**: Difficulty tiers (`Easy`, `Medium`, `Hard`) with instant feedback and deep explanations.
- **Comparison & Decision Hub**: Master Mind Map, Comparison Matrix, and Face-Off comparisons.

---

## 🚀 Getting Started

### Prerequisites
- Java JDK 17 or higher (Java 21+ recommended)

### 1. Run the Full-Stack Web Application
```bash
# Compile
javac JavaCollectionsMasteryCLI.java JavaCollectionsFullStackApp.java

# Run Server
java JavaCollectionsFullStackApp
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

---

### 2. Run the Terminal CLI
```bash
# Compile
javac JavaCollectionsMasteryCLI.java

# Run CLI
java JavaCollectionsMasteryCLI
```
